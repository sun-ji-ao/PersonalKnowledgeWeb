## 实施约束

- 免费 SQLite；canonical html_source 是唯一可编辑正文，html_rendered 绑定同修订；读取不重转 Markdown。
- 所有公开输出只从 published_revision_id 派生；草稿、历史、来源原件不通过 DTO/搜索/分类/feed/导出/媒体入口泄漏。
- 图片/附件存受管理私有目录，依据当前发布引用放行匿名读取；缺失资源补传生成新草稿，不原地改历史。
- 发布、撤回、恢复、媒体替换与并发编辑遵守版本校验；保存或展示失败不损坏旧发布内容。
- 所有服务/测试使用显式隔离 DATA_DIR。默认真实库、原站代码、253 篇原文保持原样。不执行原站 build、正式迁移、部署、提交或推送。
- 公开站点功能只在显式 HTML 模式接入；默认 Markdown MVP 保留回退路径。现有 4310/4312/4313/4314 进程不要任意停止，最终验收使用新隔离端口 4315。
- 文档集中 doc/technical-notes-lab，历史批次证据不改写。验收未执行不勾选。
