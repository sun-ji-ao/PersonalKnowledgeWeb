## 实现

- `legacy_urls` 仅在目标笔记已有发布版本时返回 302 至 `/notes/{id}`；未知与未发布旧路径返回 404。查询参数不参与映射；页面内脚本将已登记的旧标题 hash 映射到新 HTML 的标题 ID，数据库中有 253 条旧 URL 和 4,410 条标题锚点。映射生成会逐篇校验旧目录与新标题的顺序、级别及文本。
- HTML 模式的会话和登录失败计数存于独立 `auth.sqlite`，服务重启后会话仍有效；正式模式要求 HTTPS `PUBLIC_ORIGIN`、禁用示例内容及应用目录外的数据目录。RSS 与 sitemap 使用显式公开 origin。新增 `/_health`。
- 备份包含 SQLite 在线一致性副本、原始 Markdown 归档、媒体文件与校验清单。恢复脚本把备份放入新目录，启动隔离实例，核对数据库完整性、公开数量、旧 URL、匿名权限及 RSS origin。备份没有自动覆盖运行中数据库。
- 提供 Ubuntu 的服务、定时备份和反向代理模板；在这台服务器上没有启用 root 级模板，因为现有 Nginx 已用于其他服务，且 `sunjiao` 没有免密 sudo。当前实际运行入口是 `deploy/private-preview.sh`，另为该用户配置了 cron `@reboot` 启动和每天 03:15 的联合备份；手动启动与手动备份已通过，尚未观察真实重启/定时触发。
