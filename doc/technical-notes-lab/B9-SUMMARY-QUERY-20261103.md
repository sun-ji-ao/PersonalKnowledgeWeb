## 改动

- publicSummaryList 使用单次 JOIN，只读当前已发布修订的 id、created_at、published_at、revision_id、title、description、tags、category；同时匹配修订所属文章，按 published_at DESC、id 排序。
- 首页、分类、标签、归档、搜索、RSS、sitemap 使用摘要；搜索继续使用已有的持久化全文索引。
- 删除所有 HTML GET 请求共用的无条件完整列表读取，详情、登录页、重定向等不再因经过路由而加载全部正文。
- 新增 GET /api/public/notes?view=summary。默认 GET /api/public/notes 仍返回完整展示 DTO，详情与导出契约不变。原完整接口的 16.5 MB 体积因此仍保留；需要列表元信息的调用方应显式采用摘要模式。
- 没有修改数据库结构、写入流程、原始文章、发布规则、依赖、缓存或分页行为。
